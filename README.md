# Solar PV Power Generation Forecasting with Machine Learning

An supervised machine learning project designed to forecast
photovoltaic power generation using historical production data,
environmental measurements, and time-based features.


## Business Problem

A photovoltaic system operator needs to anticipate how much solar
power will be available over an upcoming period.

The business question addressed by this project is:

> How accurately can we forecast solar PV power generation using
> information available at the time of prediction?

The intended users are PV system operators and energy managers.
The forecasts are intended to support energy planning and the
scheduling of flexible electricity consumption.
